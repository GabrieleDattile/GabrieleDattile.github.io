2. Linux OPSEC, Privacy & Defensive Tooling

PrivacyToolkit Bash / Shell

Modular Linux operational privacy toolkit grouping scripts for anonymous routing (AnonSurf.bash), GnuPG cryptographic workflow setup (GNUPrivacyAssistant.bash), file metadata stripping (meta data cleaner), secure data wiping (secure file deleter), and encrypted container management (zulucrypt.sh).

SecurityTools Bash / Shell

Automated Linux defensive hardening suite composed of modular installers for host firewalls (firewall_installer.sh), system monitoring (monitoring_install.sh), credential vaults (password_manager_installer.sh), cryptographic tooling (secure-crypto-installer.sh), and threat protection (threat_protection_installer.sh).

ShieldedProxy Bash / Shell

Features SSHProxyGuard, a Bash utility designed to establish and manage encrypted SSH tunnels for safer traffic routing through public proxies.

StealthShell Bash / Shell

Bash script (StealthShell.sh) implementing shell session privacy controls, including command history suppression inside Linux terminal environments.

Chatgpg-pythonITA Python • GnuPG

Encrypted peer-to-peer Python socket chat integrating gnupg public-key cryptography for key generation, export/import, message encryption, and decryption.

macchangerITA & SimplenetcatITA Bash / Networking

Lightweight Linux network utilities: MacchangerITA.sh uses ip and openssl for randomized or custom MAC address spoofing; Simplenetcat.sh streamlines TCP listener and client connections over nc.
