Agent Superpowers: Deterministic Framework for Autonomous AI Software Engineers

Author: Gabriele D'Attile Language: TypeScript & Python Repository: GabrieleDattile/agent-superpowers

Agent Superpowers is an open-source, deterministic 7-stage autonomous engineering framework developed by Gabriele D'Attile. It is built to prevent AI coding hallucinations, broken production commits, and excessive token context bloat across major agent ecosystems including Claude Code, Cursor, Google Antigravity, Windsurf, Codex, and Model Context Protocol (MCP).

Core Design Principle: Rather than letting an LLM edit production code immediately on assumptions, Agent Superpowers enforces deterministic gates: bug reproduction first, isolated sandbox execution, minimal surgical patching, adversarial fuzzing, and full regression verification.

1. The Deterministic Execution Pipeline

Stage Gate Engineering Guarantee
1. Deterministic Repro RED Test Required Zero production code edits are allowed until an isolated test replicates the reported defect.
2. Ephemeral Sandbox Worktree Isolation Protects the primary working branch from corrupting edits during autonomous iterations.
3. Minimal Surgical Patch GREEN Verification Applies minimal targeted changes until the failing reproduction test passes reliably.
4. Red-Team Fuzzing Security Payloads Audits proposed patches against boundary overflows, null-bytes, and injection edge cases before merge.
5. Production Gate Verified Merge Full regression suite execution and verification prior to completion.

2. Modular Skill Architecture (36 Production-Grade Skills)

The repository organizes 36 modular skills inside skills/ across 12 specialized engineering domains:

  • Architecture & Reverse Engineering: architecture, reverse-engineering, and codebase cartography workflows.
  • Security & Testing: security and testing pipelines including adversarial pre-commit auditing and zero-assumption replication.
  • Debugging & Optimization: debugging and optimization modules for AST-level context compression and token efficiency.
  • Orchestration & Workflow: orchestration, workflow, memory, frontend, multimedia, and scraping.

3. Native Cross-Platform & MCP Integration

Agent Superpowers ships with installers for Windows (install.ps1), Linux/macOS (install.sh), and Python (install.py), alongside native configuration hooks for .claude-plugin, .cursor, .codex, .windsurfrules, a dashboard, a CLI, and a Model Context Protocol server (mcp/server.py) implementing JSON-RPC 2.0.
